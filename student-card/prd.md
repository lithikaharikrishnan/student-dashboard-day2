Product Requirements Document (PRD)
1. Product Name

Student Card Management System Using Reusable Components

2. Project Description

The Student Card Management System is a web-based dashboard developed using React.js. It helps administrators manage student details through reusable UI components.

3. Problem Statement

Managing student information manually can be difficult and time-consuming. This application provides a simple dashboard to organize and manage student records.

4. Project Goals
Build an easy-to-use student dashboard.
Display student information clearly.
Implement reusable React components.
Provide basic student management operations.
Create a responsive user interface.
5. Target Users
College Administrators
Teachers
Academic Staff
6. Functional Requirements
Dashboard
Display total student count.
Display active student count.
Display inactive student count.
Student Management
Display student cards.
Add new student information.
Delete student records.
View student profile details.
Search
Search students by name.
Display matching student cards.
7. Reusable Components
StudentCard.jsx

Displays individual student details.

StudentForm.jsx

Provides a form to add new student information.

StudentList.jsx

Displays multiple student cards using React map functionality.

8. Non-Functional Requirements
Responsive layout.
User-friendly interface.
Reusable and maintainable code.
Consistent styling.
Fast rendering.
9. Technology Stack
React.js
JavaScript
HTML5
CSS3
Vite
Lucide React
10. Success Criteria
Dashboard displays student statistics.
Student cards render correctly.
Add student functionality works.
Search functionality works.
Delete functionality works.
View profile functionality works.
Components can be reused.
