Student Card System Using Reusable Components
Project Overview

The Student Card Management System is a React-based dashboard designed to manage student information using reusable components.

The dashboard provides a simple and user-friendly interface to view, add, search, and delete student details.

Objectives
Create a responsive student dashboard.
Use reusable React components.
Display student information in individual cards.
Add new student details.
Search students by name.
View individual student profiles.
Delete student records.
